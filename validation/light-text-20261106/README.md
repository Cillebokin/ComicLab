# 轻量文字检测逐框复查与背景筛选实验

## 范围和标注

从之前50页作品均衡样本中选取5页（sample-00、08、12、23、45，来自不同作品），对基础版全部228个候选框逐一查看编号裁图，记录在annotations.json中。原始样本路径及副本SHA-256见mapping.json。分类由助手单人目视完成，没有独立人工复核，也没有完整标注所有真实文字；25个不确定框保留为uncertain。5页被用于确定实验方向，不是独立测试集。

| 视觉类别 | 数量 | 含义 |
| --- | ---: | --- |
| background | 88 | 人物、画格或纹理等非文字区域 |
| split_merge | 44 | 文字碎片或跨多列误分组 |
| oversized_text | 24 | 包含文字且混入大面积画面或多个区域 |
| text | 47 | 可以辨认的文字候选；不意味着边界一定正确 |
| uncertain | 25 | 字体过小、水印或难以确认 |

这些类别互斥，不是整体数据集误检率。5页未发现坐标完全相同或IoU≥0.6的框对；低重叠的重复及嵌套框没有完整标注，不能断言重复框为零。annotations.json另列7处目视确认的未被可用文字框覆盖的例子，其中1处短对白两种检测器都未框出；这些是例子而不是完整漏检清单，无法计算真实召回率。

## 优化与对比

针对数量最多的背景类，实验性提高候选框外围亮色或暗色背景的一致性门槛，同时保留原有灰度选项。由于会影响复杂背景上的文字，`strictBackground`默认关闭，正式翻译仍使用原DBNet、OCR和AOT-GAN。不同模式使用同样50张图片、相同缩放和已保存的DBNet参考框；输入副本SHA-256、尺寸及默认版逐页检测框和掩码白色像素数均已核对。

| 50页结果 | 原基础版 | 40%门槛 | 60%门槛 |
| --- | ---: | ---: | ---: |
| 轻量候选框 | 4,600 | 3,868 | 2,451 |
| 与DBNet框匹配 | 613 | 608 | 593 |

匹配为轴对齐框IoU≥0.3贪心一对一，DBNet不是人工真值。40%门槛：5页中移除31个background、3个oversized_text和2个uncertain，匹配数50→49；其余45页未逐框标注，候选框4,372→3,676、匹配563→559，其中部分新候选来自原本达到上限的页面。60%门槛进一步减少候选，但5页与其余45页匹配分别50→48和563→545，目视损失示例包含真实文字。总匹配数不能保证每个原匹配文字都仍被覆盖。

门槛实验发现背景误检确有改善空间，但也可能丢失背景较复杂、靠近画格或对白气泡边缘的文字，因此不能默认启用或据此声称准确率提升。5页以外的45页仍是从10部作品每部抽取5页的样本，不代表完整漫画库。

## 验证限制

本轮50页运行于x86_64模拟器，正式OCR、翻译和AOT-GAN整页效果及真机速度未验证。`moderate-analysis.json`、`strict-analysis.json`保存逐页指标；预览图和批量原始输出保存在`app/build/translation-validation/frame-holdout-20261105`，可能被Gradle清理。实际图片素材保留在原目录，未修改。
