Windows 共享设置

  1. 共享文件夹：右键漫画文件夹，进入属性 → 共享 → 高级共享，勾选“共享此文件夹”，记下共享名。
  2. 确认网络：手机和电脑连接同一个 Wi-Fi。在 Windows 11 打开设置 → 网络和 Internet → Wi-Fi → 已连接的网络，将“网络配置文件类型”设为“专用”；再打开设置 → 网络和 Internet → 高级网络设置 → 高级共享设置 → 专用网络，开启“网络发现”和“文件和打印机共享”。
  3. 获取 IP：打开设置 → 网络和 Internet → Wi-Fi → 已连接的网络，在属性中找到“IPv4 地址”。
  4. 手机连接：ComicLab 进入设置 → NAS，启用 NAS 并添加 Windows 共享，填写电脑 IP 和共享名，点击“测试连接”。

填写提醒：共享名不是电脑上的完整路径。例如 D:\Comic 共享为 Comic，手机端填 Comic。需要账号时用户名和密码都填（密码不是 PIN）；匿名访问时两项留空。
