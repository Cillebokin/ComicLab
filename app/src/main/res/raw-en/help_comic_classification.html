Comic Classification

ComicLab checks comic files in the current folder and its subfolders, then copies them into separate folders based on their feature markers. The original files are kept.

Where do the classified files go?

  1. A new folder is created in the current folder, for example ClassifyNList000. If that name is already in use, ComicLab uses the next number
  2. Comics with a feature marker go into a folder named after the marker. Comics without one go into ClassifyNListNoTag
  3. If a file with the same name already exists, ComicLab adds a number to the copied file's name instead of overwriting it

Examples

[ABC]作品名称.zip
Copied to ClassifyNList000/ABC/[ABC]作品名称.zip

作品名称.zip
With no feature marker, copied to ClassifyNList000/ClassifyNListNoTag/作品名称.zip
