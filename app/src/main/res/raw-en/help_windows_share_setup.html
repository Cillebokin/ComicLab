Set up a Windows share

  1. Share a folder: Right-click the comic folder, open Properties → Sharing → Advanced Sharing, select “Share this folder”, and note the share name.
  2. Check the network: Connect your phone and PC to the same Wi-Fi. In Windows 11, open Settings → Network & internet → Wi-Fi → connected network and set Network profile type to Private. Then open Settings → Network & internet → Advanced network settings → Advanced sharing settings → Private networks and turn on Network discovery and File and printer sharing.
  3. Find the IP address: Open Settings → Network & internet → Wi-Fi → connected network and find the IPv4 address under Properties.
  4. Connect in ComicLab: Open Settings → NAS, enable NAS, add a Windows share, enter the PC’s IP address and share name, then tap “Test connection”.

Remember: The share name is not the full local path. If D:\Comic is shared as Comic, enter Comic on your phone. Fill in both username and password when required (the password is not your PIN); leave both empty for anonymous access.
