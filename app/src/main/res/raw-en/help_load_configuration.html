Load Configuration

Choose a configuration file you exported earlier to load its valid records and settings into ComicLab.

How to load

  1. Open Settings and find Configuration management near the bottom
  2. Tap Load configuration and choose the configuration file

Your existing valid records are kept and merged with the imported data. Imported app settings are applied to this device.

If a comic file or folder cannot be accessed, or a comic file is not supported, its record is skipped while other valid data is restored. When loading is complete, ComicLab shows how many items were restored and skipped.
