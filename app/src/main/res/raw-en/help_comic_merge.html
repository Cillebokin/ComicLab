Merge Comics

Extract images from several comic archives into one new folder so you can browse them together. The original archives are kept.

How to use it

  1. Open the folder containing the comic archives
  2. Tap Merge comics in the menu
  3. The images are placed in a new ComicLab_merged_... folder in the current folder and renumbered, for example 0001.jpg

Only comic archives in the current folder are processed. Archives in subfolders are not searched.

This extracts the images from the archives; it does not create a new comic archive.
