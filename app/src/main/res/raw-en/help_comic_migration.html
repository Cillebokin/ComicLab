Step-by-step migration

ComicLab shows you one comic at a time. Choose a folder for each comic before the next one appears.

When you tap a folder, ComicLab copies the comic there and keeps the original in its source location. The next comic appears after the copy finishes.

Choose two locations first

  1. Target location: The location containing the folders where you want to put your comics. ComicLab searches from here down
  2. Default storage location: Choose this if none of the listed folders is suitable. It always appears at the bottom of the list

Choosing a folder

  1. ComicLab checks for comics in the source folder and its subfolders, then shows them one by one
  2. The top of the window shows the filename and its feature marker. The marker is the text ComicLab uses to look for folders; null means no marker was found
  3. The list shows possible folder names and paths. ComicLab may suggest the wrong folder, so check the path before tapping it
  4. You must choose a location for each comic. The next one appears after the copy finishes

If a file with the same name already exists in the destination, ComicLab skips that comic and does not overwrite the existing file. If a copy fails, it shows a failure status and continues with the next comic.

If a feature marker consists only of Japanese kana or only of Roman letters, ComicLab also tries to find the other spelling, for example あまみ and amami. Check these suggestions yourself too.

Note

The stop button ends the entire process. The remaining comics will not be processed.
