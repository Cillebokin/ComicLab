Merge Files

Collect images from the subfolders of the current folder into one new folder. The original images are kept.

How to use it

  1. Open the folder that contains the image folders
  2. Tap Merge files in the menu
  3. The images are copied into a new ComicLab_file_merged_... folder in the current folder and renumbered

Only images directly inside the next-level subfolders are processed; deeper folders are not searched. Supported formats: JPG, JPEG, PNG, WEBP, GIF, and BMP.

Example
