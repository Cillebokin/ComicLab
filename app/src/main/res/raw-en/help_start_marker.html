Feature Marker

A feature marker is the first bracketed text in a comic filename that meets the rules below. ComicLab can use it to classify comics.

How it is identified

  1. Use square brackets []
  2. The text inside the brackets cannot be empty
  3. It must not contain a feature marker error tag
  4. If a bracketed text does not meet these rules, ComicLab checks the next pair of []

Examples

[ABC]作品名称.zip
Feature marker: ABC

[中] [ABC]作品名称.zip
If 中 is an error tag, ComicLab skips it and checks [ABC]
