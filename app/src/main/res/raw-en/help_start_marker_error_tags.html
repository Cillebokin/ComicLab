Feature Marker Error Tags

These tags exclude bracketed text that should not be used as a feature marker.

Where to find this setting

Settings → File Browser → Feature marker error tags

How to enter tags

Separate multiple tags with an English semicolon ;. Changes are saved automatically.

Default tags

中;汉;漢;翻;译;譯

Example

[中] [ABC]作品名称.zip
If 中 is an error tag, ComicLab skips it and checks [ABC]

Clear this setting to stop excluding any error tags.
