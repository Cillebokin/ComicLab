漫画分类

根据漫画文件名中的特征标记，将漫画文件复制到分类目录，原文件会保留。

分类规则

  1. 递归扫描当前目录及其子目录中的漫画文件，跳过隐藏目录和已生成的分类目录
  2. 在当前目录创建 ClassifyNList000；已存在时使用下一个可用编号
  3. 根据特征标记创建子文件夹；没有特征标记的文件放入 ClassifyNList000/ClassifyNListNoTag
  4. 如果目标位置已有同名文件，副本会自动添加编号，不会覆盖原文件

示例

[ABC]作品名称.zip
分类到 ClassifyNList000/ABC/[ABC]作品名称.zip

作品名称.zip
没有特征标记时，分类到 ClassifyNList000/ClassifyNListNoTag/作品名称.zip

逐条迁移

程序会一份一份地显示漫画，让你决定每本漫画应该放到哪个文件夹。选好一本后，才会显示下一本。

点击一个文件夹后，程序会把这本漫画复制到那里，原文件仍留在源位置。复制完成后才会显示下一本。

开始前先选两个位置

  1. 目标位置：你想把漫画放进去的那些文件夹所在的位置。程序会从这里往下寻找
  2. 默认存放位置：如果下面列出的文件夹都不合适，就选这个位置。它会出现在列表最后

怎么选择文件夹

  1. 程序会检查源位置和里面子文件夹中的漫画，然后逐本显示
  2. 每本漫画都会显示文件名和“特征标记”。特征标记是程序从文件名中找来帮助寻找文件夹的文字；显示 null 表示没有找到
  3. 下面会列出一些可能合适的文件夹名称和路径。程序只是帮你找，可能会找错，请看清路径后再点击
  4. 每本漫画都要点选一个位置；复制完成后才会进入下一本

如果目标文件夹里已经有同名文件，程序会跳过这本，不会覆盖已有文件。复制失败时会显示失败状态，然后继续处理下一本。

如果特征标记是纯日文假名或纯罗马字，程序也会尝试寻找对应的另一种写法，例如 あまみ 和 amami。这类结果也请自己确认。

注意事项

点击“终止迁移”会停止整个流程，剩下的漫画不会继续处理。
