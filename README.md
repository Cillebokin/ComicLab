# ComicLab

ComicLab 是一个面向 Android 的本地漫画阅读器，主要用于浏览手机存储中的漫画文件，并阅读 ZIP、CBZ、RAR、CBR、7Z、CB7 等格式的漫画压缩包。

项目当前重点是本地文件浏览、漫画封面预览、漫画预览、高清阅读和阅读进度管理。

**如果您也在使用，并且存在需求和问题，请反馈给作者（比心）**

## 支持格式

| 类型 | 格式 |
| --- | --- |
| 漫画压缩包 | ZIP, CBZ, RAR, CBR, 7Z, CB7 |
| 图片 | JPG, JPEG, PNG, WEBP, GIF, BMP |

## 运行环境

- Android 13 或更高版本
- 需要授予“管理所有文件”权限
